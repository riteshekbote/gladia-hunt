## LEAD 1: npm `gladia@0.1.3` package impersonates official SDK (supply-chain confusion)

**Assets:** npm registry `gladia` 0.1.3 (dist-tag `latest`)
**Models reporting:** bigpickle, laguna, nemotron3 (confidence 78–80)

| Q# | Answer |
|---|---|
| Q1 | **YES** — npm is an official SDK channel per scope.yml (MEDIUM priority) |
| Q2 | **YES** — public npm registry, `npm view` reachable by anyone |
| Q3 | **YES** — real supply-chain risk: package description claims "Official TypeScript SDK for Gladia" while README says "Unofficial"; repo is personal `alexisbouchez/gladia.ts`, maintainer `softwarecitadel@gmail.com`, published 2025-03-28 predating `@gladiaio/sdk` (2025-09-09). Developers installing `gladia` get unofficial code; future account/repo hijack → supply-chain compromise |
| Q4 | **YES** — fully provable via `npm view gladia@0.1.3 description repository.url maintainer` + tarball inspection (benign code, but ownership anomaly is the finding) |
| Q5 | **YES** — verified active as of 2026-08-09; not previously reported to Gladia |
| Q6 | **YES** — not on always-rejected list; this is an ownership/impersonation anomaly, not a best-practice nitpick |
| Q7 | **YES** — a reasonable triager would accept this as a real supply-chain hygiene finding (Medium) |

### Verdict: **VALID** ✅

**Minimal read-only proof:**
1. `npm view gladia@0.1.3 description` → `"Official TypeScript SDK for Gladia"`
2. `npm view gladia@0.1.3 repository.url` → `github.com/alexisbouchez/gladia.ts` (personal, not `gladiaio`)
3. `npm view gladia@0.1.3 maintainer` → `softwarecitadel <softwarecitadel@gmail.com>`
4. Download tarball, inspect README title → `"Unofficial TypeScript SDK"`
5. Compare publish dates: `gladia@0.1.3` = 2025-03-28 vs `@gladiaio/sdk` = 2025-09-09

**Impact:** Developers installing `gladia` instead of `@gladiaio/sdk` run unofficial, unaudited code. If the personal maintainer account is hijacked, malicious code could be pushed to `latest` tag → supply-chain compromise.

**CVSS 3.1:** AV:N/AC:L/PR:N/UI:R/S:U/C:N/I:N/A:H → **4.3 (Medium)** — future-hypothetical impact, not active exploitation
